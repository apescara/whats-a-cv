# Senior Data Engineer — Sodimac

## Scope

Integró un equipo mixto de Data Scientists y Data Engineers responsable de convertir pipelines y modelos de Machine Learning en procesos productivos, confiables y escalables sobre GCP.

## Achievements

- Diseñó la plataforma de ejecución de procesos de ML mediante imágenes Docker en Artifact Registry, orquestación con Cloud Composer y ejecución en GKE con node pools de distintos tamaños según la carga.
- Implementó CI/CD con GitLab CI a partir de un repositorio central de templates y pasos reutilizables por los pipelines de cada proyecto.
- Migró Airflow de la versión 1 a la 2 sin interrupciones en los procesos productivos.
- Desarrolló operadores personalizados de Airflow para administrar mejor los recursos de Kubernetes y prevenir fallas por cuotas.
- Creó un repositorio central de features en BigQuery que integraba APIs, web scraping e indicadores macroeconómicos, monedas y materias primas para acelerar el feature engineering.
- Mantuvo y mejoró una librería interna de Python para reutilización de código e implementó monitoreo de costos y consumo de recursos.
- Administró roles y permisos de IAM para el equipo de Data Science y gobernó entidades sin uso en BigQuery y Cloud Storage.
- Asumió la continuidad y evolución de modelos heredados, entre ellos una segmentación corporativa de clientes basada en reglas de negocio y XGBoost, y la detección de productos con bajo desempeño mediante Prophet.

## Skills

- Python, Airflow, Cloud Composer, GKE, Kubernetes, Docker, Artifact Registry, BigQuery, Cloud Storage, GitLab CI, CI/CD, IAM, XGBoost, Prophet, FinOps, feature engineering y Machine Learning.
