# Machine Learning Engineer — Sodimac

## Scope

Da soporte operativo y técnico a un equipo de entre 6 y 15 integrantes que desarrolla soluciones de Machine Learning e IA. El entorno comprende cerca de 200 repositorios, 260 DAGs de Airflow, más de 40 APIs y una plataforma interna utilizada diariamente por más de 100 usuarios de negocio.

## Achievements

- Redujo la duración promedio del pipeline de CI en Cloud Build de siete a dos minutos mediante imágenes Docker base, scripts Bash, adopción de uv y `pyproject.toml`, y actualización controlada de Python sin romper soluciones legadas.
- Incorporó Terraform para administrar y escalar Cloud Composer y GKE, e implementó una API que selecciona dinámicamente las máquinas para procesos de ML según su consumo histórico.
- Estandarizó el feature engineering de múltiples proyectos mediante dbt y creó templates para unificar la forma de trabajo.
- Desarrolló en TypeScript y Next.js la nueva versión de una plataforma interna utilizada diariamente por más de 100 usuarios de negocio, migrándola desde Django en App Engine e incorporando login corporativo mediante OpenID Connect contra Active Directory —intermediado por Keycloak—, validación de permisos basada en roles y soporte para aplicaciones embebidas mediante iframes.
- Automatizó el despliegue de nuevas aplicaciones a partir de sus contratos OpenAPI y creó agentes, skills y lineamientos internos para mantener los estándares de desarrollo.
- Fortaleció una plataforma de más de 40 APIs con CI/CD para API Gateway, un template basado en FastAPI y ADK con telemetría y control de acceso, una aplicación Streamlit para generar nuevos servicios, y APIs centralizadas de autenticación, logging, costos y consumo.
- Implementó un gateway corporativo para modelos generativos y un wrapper interno que redujo a la mitad las líneas necesarias para consumirlo; incorporó trazabilidad de uso mediante Langfuse y centralizó sus proyectos en la plataforma interna.
- Creó un flujo para convertir aplicaciones de AI Studio en servicios desplegados en Cloud Run e integrados por iframe, utilizando un proxy Nginx cuando requerían acceso al gateway de IA.
- Capacitó a más de 80 usuarios en el uso básico de Claude y actuó como focal point de Sodimac para la administración de usuarios y presupuesto.

## Responsibilities

- Gestiona el backlog del equipo de Data Engineering y mantiene paneles de seguimiento para gasto y consumo de APIs internas.
- Administra Vertex AI Workbench con Terraform sobre una red privada dedicada por requisitos de seguridad.
- Mantiene un repositorio central de agentes y skills para acelerar el desarrollo y la documentación.
